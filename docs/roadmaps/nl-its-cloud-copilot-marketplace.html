Operating model

One sanctioned marketplace in Deloitte-Netherlands. Team members register it in VS Code once. Projects install only the plugins they need. The catalog includes five internal plugins plus approved external plugins that pass Deloitte compliance review.

Plugins bundle agents, subagents, skills, scripts, and MCP. Org-level custom agents graduate from private testing in .github-private to org-wide release after security and CoE approval.

Internal plugin portfolio

Approved external plugins

Third-party plugins are listed only after Deloitte compliance review (license, security, data handling, maintenance). Prefer org-owned mirrors under Deloitte-Netherlands.

CriterionRequirement
LicenseCompatible with organizational use
SecurityScripts and MCP reviewed; no malicious patterns
DataNo unauthorized exfiltration of client or restricted data
AuditRecord in catalog/external/*.yaml with reviewer and date

Team members install external plugins only from nl-its-cloud-ai-marketplace — not from public marketplaces directly.

Team member setup — VS Code

  1. Register marketplace: /plugin marketplace add Deloitte-Netherlands/nl-its-cloud-ai-marketplace
  2. Install per project, e.g.:
    /plugin install agentic-infra-ops@nl-its-cloud-ai-marketplace
    /plugin install servicenow-ops@nl-its-cloud-ai-marketplace
  3. Verify agents in Copilot Chat agent picker.
  4. Update after merges: /plugin marketplace update nl-its-cloud-ai-marketplace

Accountability line

Plugin agents and subagents propose drafts at each gate. Skills teach specialized tasks. GitHub Actions execute deploy (Tier 3+). Humans approve at every stage. ServiceNow change may be required before deploy.
