# Review Terraform plan

## When to use
Use when the user provides terraform plan output.

## Steps
1. Parse plan for create/update/destroy counts
2. Check naming and tagging standards
3. Flag high-risk resources
4. Output structured review table

Hands-on steps

  1. Fork nl-its-cloud-ai-marketplace and create branch skill/your-skill-name
  2. Add plugins/<plugin>/skills/<name>/SKILL.md with frontmatter and numbered steps
  3. Install plugin locally and test in Copilot Chat with the owning agent
  4. Add eval stub under evals/skills/<name>/ (input + expected)
  5. Open PR — describe triggers, risk tier, and reviewer path
  6. After merge: /plugin marketplace update and /plugin update

Exercise

  • Study plugins/diagram-design/skills/diagram-design/SKILL.md in this repo as a reference
  • Identify one gap: a sub-procedure that deserves its own skill or references/ split
  • Draft frontmatter + When to use + Steps; assign risk tier and owner
  • (Optional) Open a draft PR with an eval stub
