What is a GitHub Copilot plugin?

A plugin is a distributable package that extends Copilot with agents, skills, hooks, and integrations — bundled in a single installable unit for VS Code, Copilot CLI, and cloud agent.

Figure 1 — Plugin components bundled in one installable unit

Directory structure

nl-its-cloud-ai-plugin/
├── plugin.json           # Required manifest
├── agents/               # Custom agents (optional)
│   └── helper.agent.md
├── skills/               # Skills (optional)
│   └── deploy/SKILL.md
├── hooks.json            # Hook configuration (optional)
├── .mcp.json             # MCP server config (optional)
└── lsp.json              # LSP server config (optional)

Why plugins vs manual configuration?

ScopeSingle repositoryAny project
SharingManual copy/pasteInstall command or enabledPlugins

  • Reusability across projects

  • Encapsulate complex MCP server setups

How marketplaces work

A marketplace is a registry of versioned plugins — our sanctioned catalog is Deloitte-Netherlands/nl-its-cloud-ai-marketplace, defined by marketplace.json.

Figure 2 — Register marketplace once in VS Code; install plugins per project; declare in repo settings

Hands-on — VS Code setup

  1. Confirm GitHub Copilot license and install Copilot + Copilot Chat extensions in VS Code.
  2. Register the org marketplace in Copilot Chat:
    /plugin marketplace add Deloitte-Netherlands/nl-its-cloud-ai-marketplace
  3. Verify: /plugin marketplace list — should show nl-its-cloud-ai-marketplace.
  4. Install a plugin for your project:
    /plugin install diagram-design@nl-its-cloud-ai-marketplace
  5. Open agent picker — confirm plugin agents appear (e.g. diagram-designer).
  6. Add enabledPlugins to your repo's .github/copilot/settings.json.
  7. Update after marketplace merges: /plugin marketplace update nl-its-cloud-ai-marketplace

CLI alternative

copilot plugin marketplace add Deloitte-Netherlands/nl-its-cloud-ai-marketplace
copilot plugin install agentic-infra-ops@nl-its-cloud-ai-marketplace

Repository settings example

{
  "enabledPlugins": {
    "agentic-infra-ops@nl-its-cloud-ai-marketplace": true,
    "servicenow-ops@nl-its-cloud-ai-marketplace": true
  },
  "extraKnownMarketplaces": {
    "nl-its-cloud-ai-marketplace": {
      "source": { "source": "github", "repo": "Deloitte-Netherlands/nl-its-cloud-ai-marketplace" }
    }
  }
}
